# Roadmap

## v0.1.0 — Self-hostable foundation
- Four engines with bounded capabilities.
- MCP Streamable HTTP endpoint.
- PostgreSQL persistence.
- React companion dashboard.
- Token protection for single-tenant deployments.
- Docker deployment and setup documentation.

## v0.2.0 — ChatGPT-native experience
- MCP Apps UI resources and interactive widgets.
- OAuth authorization.
- Per-user identity and tenant isolation.
- Per-integration consent and revocation.

## v0.3.0 — Developer integrations
- GitHub App installation.
- Pull request review drafts with approval.
- Repository indexing and incremental analysis.

## v0.4.0 — Community extensions
- Versioned extension contract.
- Capability permission manifest.
- Extension compatibility tests.

## Out of scope for v0.1.0
- Arbitrary shell execution.
- Arbitrary generated-code execution.
- Autonomous commits or deployments.
- Multi-tenant hosted SaaS.
